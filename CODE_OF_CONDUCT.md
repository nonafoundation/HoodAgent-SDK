# Code of Conduct

This project follows the [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good intent, keep discussion technical, and never post anyone's private keys,
seed phrases or personal data. Harassment, spam and scams (including fake "support" DMs) lead to removal.

Report conduct issues privately via **Security → Report a vulnerability** on this repository, marked "Conduct".
